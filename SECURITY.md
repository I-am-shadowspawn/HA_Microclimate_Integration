# Security policy

> **Unofficial, independent project.** This integration and its custom cards are not affiliated with, endorsed by, or supported by Microclimate. Their only connection to Microclimate is that they work with its products. Product names are used solely to identify compatibility. For integration support, use this project’s [GitHub Issues](https://github.com/I-am-shadowspawn/HA_Microclimate_Integration/issues).

Use [GitHub private vulnerability reporting](https://github.com/I-am-shadowspawn/HA_Microclimate_Integration/security/advisories/new) for suspected vulnerabilities, credential disclosure or unauthorized writes. It was enabled for this repository on 25 September 2026. Do not put sensitive details in public Issues. If the private form is unavailable, open an issue requesting that private reporting be enabled, without including the vulnerability or any credentials.

Include the affected integration/HA versions, reproduction steps with dummy credentials, impact and a suggested fix if available. Do not send live device tokens or perform tests on devices you do not own or control. If a token is exposed, revoke or replace it through the provider and reconfigure the integration.

The current development candidate is 1.3.0; V2 is not yet released. Security fixes target the current development line and, once published, the latest stable release. Older candidates have no guaranteed backport support. This volunteer project cannot promise a response deadline; coordinate disclosure privately through the advisory thread.

Release maintainers must retain private reporting, avoid credential-bearing logs/artifacts and rerun the release checks before publishing a fix.
